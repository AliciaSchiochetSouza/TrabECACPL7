# Music Emotion Recognition

Projeto desenvolvido no âmbito da unidade curricular **Feature Engineering for Machine Learning**, do **Departamento de Engenharia Informática da Universidade de Coimbra**.

## Sobre o projeto

O objetivo deste projeto é explorar a aplicação de **Machine Learning ao reconhecimento de emoções na música (Music Emotion Recognition)**.

Para isso, são utilizadas diferentes fontes de informação associadas a cada música:

- **Áudio**
- **Letras**
- **Capas de álbuns**
- **Metadados**

Através da análise e transformação destas diferentes fontes de dados, o projeto procura desenvolver características (*features*) relevantes para a construção de modelos capazes de **prever a categoria emocional associada a cada música**.

## Principais etapas

O desenvolvimento do projeto inclui:

- Compreensão e exploração do conjunto de dados;
- Análise exploratória dos dados;
- Identificação e tratamento de valores em falta, duplicados, erros e *outliers*;
- Análise da distribuição das classes;
- Pré-processamento dos dados;
- Engenharia e seleção de características;
- Exploração de representações aprendidas;
- Tratamento do desequilíbrio entre classes;
- Desenvolvimento e validação de modelos de Machine Learning;
- Avaliação e interpretação do modelo final.

## Dados

O conjunto de dados utilizado deriva do **MERGE Bimodal Complete**, tendo sido expandido com capas de álbuns.

O projeto trabalha com diferentes modalidades de dados, organizadas em diretórios próprios, incluindo áudio, letras e capas de álbuns, juntamente com tabelas e documentação de suporte.

## Objetivo

Construir e avaliar uma abordagem multimodal de Machine Learning capaz de utilizar informação proveniente de diferentes fontes para realizar **Music Emotion Recognition**, dando especial atenção ao processo de **Feature Engineering** e ao impacto das características utilizadas no desempenho dos modelos.
